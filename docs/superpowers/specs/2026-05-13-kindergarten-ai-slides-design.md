# 幼儿园小班AI分享课 - 网页版Slides设计文档

## 概述

为3-4岁幼儿园小班儿童设计并实现一次20分钟的AI主题分享课，采用自研网页版Slides作为展示工具。核心叙事弧线：**神奇→犯错→升华**。

## 目标用户特点

- 年龄：3-4岁（小班第二学期）
- 注意力：每段3-5分钟，需高频互动
- 认知：具象化思维，不理解抽象概念
- 识字：基本不识字，全靠视觉和听觉
- 互动：喜欢举手、喊叫、发现错误

## 内容结构（20分钟，17页）

## 技术架构

### 项目结构

```
shear-kinder/
├── src/
│   ├── index.html          # 主入口
│   ├── styles/
│   │   └── main.css        # 全局样式 + 动画
│   ├── scripts/
│   │   └── slides.js       # 幻灯片控制逻辑
│   └── assets/
│       ├── images/         # 图片素材
│       └── videos/         # 视频素材
├── pyproject.toml
└── main.py                 # 启动本地服务器
```

### 技术选型

| 组件 | 选择                               | 理由                           |
| ---- | ---------------------------------- | ------------------------------ |
| 框架 | 纯HTML/CSS/JS                      | 完全控制，无需构建工具         |
| 导航 | 键盘箭头 + 触摸滑动 + 底部隐藏按钮 | 讲演者键盘控制，备用触屏       |
| 视频 | HTML5 `<video>` 自动播放+静音      | 避免浏览器自动播放策略         |
| 动画 | CSS动画 + 少量JS                   | 性能好，适合入场/退场          |
| 部署 | 本地Python HTTP服务器              | `python -m http.server` 最简单 |
| 字体 | 系统圆体（幼圆/微软雅黑）          | 无需下载，大字号显示           |

### 幻灯片控制

- 翻页：左/右箭头键，淡入淡出过渡（0.3秒）
- 进度条：底部极细进度条
- 演讲者备注：底部隐藏区域，鼠标悬停显示
- 全屏：启动时自动请求全屏
- 视频页：翻到时自动播放，播完自动进入下一页

### 视觉风格

- 背景：每段不同底色渐变（蓝紫→橙色→红→绿色过渡）
- 文字：80-120px，圆体，白色，极少
- 图片/视频：占满整屏或80%屏宽
- 动画：图片从下方弹入、文字从左滑入

### 备用方案

1. 笔记本 + HDMI线连大屏，本地服务器运行
2. U盘拷贝，学校电脑浏览器直接打开HTML
3. 导出截图PDF打印（视频不可用）
