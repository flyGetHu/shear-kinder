# 真 AI 素材生成清单

> **用途**：为《AI魔法课》网页版 Slides 准备真实 AI 生成的图片和视频素材。
> **使用方法**：按清单去豆包/即梦/ChatGPT/可灵等工具生成，下载后重命名为指定文件名，保存到对应目录，刷新页面即可自动替换 SVG 占位符。

---

## 📂 目录结构

```
src/assets/
├── images/              # 真 AI 图片（.png）放这里 — 7 个待填充
├── videos/              # 真 AI 视频（.mp4）放这里 — 3 个待填充
└── placeholders/        # ✅ 已就绪 SVG 占位符，无需改动
```

**占位符自动回退逻辑**：
```html
<img src="真图.png" onerror="...换 SVG">
```
真 `.png` 文件一旦放入 `images/` 目录，刷新页面会自动加载真图；没放则继续显示 SVG 占位符，不会出现破图。

### 6. AI 画错的手（**关键梗图**）

- **目标文件**：`src/assets/images/ai-wrong-hand.png`
- **Prompt**：
```
一张逼真的人类手部照片，但故意有 6 根手指（AI 生成的典型特征），
五根正常手指加上额外一根小指旁边的奇怪手指，干净浅色背景。
```
- **Tips**：
  - 直接用 Midjourney / 即梦输入 "realistic hand photo"，早期 AI 模型经常自动画出 6 指
  - 或让 AI 画 "一只人类的手"，多试几次自然会犯错
  - **保底方案**：用现成的 SVG 占位符（`placeholders/wrong-hand.svg`）已经很明确，或网上搜 "AI 画错的手 meme" / "AI 6 fingers meme" 找现成图

### 7. AI 画错的狗（**关键梗图**）

- **目标文件**：`src/assets/images/ai-wrong-dog.png`
- **Prompt**：
```
一只可爱的金黄色小狗站在草地上，但故意有 5 条腿（AI 画错的典型），
卡通插画风格，让错误明显可见。
```
- **Tips**：让 AI "画一只在跑的小狗"，AI 有时会自动多画腿；或直接用 SVG 占位符

## 🎬 第二批：视频（3 段）— 推荐工具：**即梦视频 / 可灵 / Runway**

### 8. 玩具变真车（约 5-8 秒）

- **目标文件**：`src/assets/videos/toy-to-real.mp4`
- **步骤**：
  1. 先拍一段你家（或找一张）玩具小汽车静态图
  2. 在即梦/可灵里上传该图，使用"图生视频 + 风格转换"
- **Prompt**：
```
让这辆玩具小汽车变成一辆真的红色汽车，在公路上飞驰，
阳光明媚，专业摄影视角。
```

### 9. AI 听错的视频（约 5 秒）

- **目标文件**：`src/assets/videos/ai-misunderstand.mp4`
- **Prompt**：
```
火车站旁边的汽车变成了一辆长得像火车站的巨型汽车在开，
整个火车站大楼被装在车顶上，荒诞有趣，风格卡通化。
```
- **技巧**：故意让 AI 误解，能产生最佳的荒诞效果

### 10. 手工变活（**压轴，最关键**）

- **目标文件**：`src/assets/videos/craft-comes-alive.mp4`
- **前置准备**：
  1. 让女儿在家里画一张她自己（或涂鸦一个小人/动物）
  2. 拍成清晰照片，存为 PNG
- **步骤**：上传到可灵/即梦的"图生视频"功能
- **主 Prompt**：
```
让画中的小人动起来，挥手、眨眼、跳舞，画面风格保持和原画一致。
```
- **备用 Prompt**（主效果不理想时）：
```
这幅画中的角色从纸上走出来，微笑挥手。
```
