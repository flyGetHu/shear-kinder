# AI魔法课 ✨

为 3-4 岁幼儿园小朋友设计的 AI 科普互动幻灯片。通过 20 分钟的分享课，带孩子们认识 AI 的神奇之处，同时理解 AI 也会犯错，学习依然重要。

## 课程结构

| 阶段 | 主题 | 时长 | 内容 |
|------|------|------|------|
| 开场 | 认识 AI | 2 分钟 | 什么是 AI，谁家里有电脑/手机 |
| 神奇 | AI 会画画、做视频、说话 | 5 分钟 | 展示 AI 生成的画作和视频 |
| 认知 | 什么是 AI | 2 分钟 | AI 像一个特别用功的小朋友 |
| 犯错 | AI 闹的笑话 | 6 分钟 | 画错的手、画错的动物、听错的指令 |
| 升华 | AI 是好帮手，学习更重要 | 3 分钟 | AI 像画笔，但画画的人是我们 |

## 快速开始

需要 Python 3.12+，无其他依赖。

```bash
python main.py
```

浏览器会自动打开 `http://localhost:8080`。

建议按 F11 进入全屏模式以获得最佳演示效果。

## 操作方式

- **翻页**：左右箭头键 / 触摸滑动
- **演讲者备注**：鼠标悬停页面底部
- **全屏**：启动时自动提示

## 项目结构

```
src/
├── index.html          # 主入口
├── styles/main.css     # 样式 + 动画
├── scripts/slides.js   # 幻灯片控制逻辑
└── assets/             # 图片和视频素材
```
